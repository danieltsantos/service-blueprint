Sample broadband blueprint

L0 service blueprint for installing broadband at a small business site

Owner unassigned · Updated 2026-11-07 · State to-be · Layer L0 · Status WIP · By Daniel Santos · Licence CC BY-NC 4.0

Executive description

  • Let small businesses order broadband online and get a working line on the first visit.

Main goals

  • Working line after the first technician visit
  • Customer always knows the next step and its date

Core user need

  • I need to know when my line will work, so I can plan around the downtime.

Key user stories

  • As a shop owner, I want to pick an installation slot that fits my opening hours.
  • As a shop owner, I want to hear early if the visit is at risk.

Metrics to move

  • % of installs working after the first visit
  • Contacts per order before the line goes live
